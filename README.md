# OBLR — Omarchy Theme

A dark monochrome Omarchy theme featuring Islamic-inspired visual symbolism, including the Zaqqum tree, thorny forms, and blood-red accents.

## Desktop Preview

![OBLR desktop preview](desktop-preview.webp)

## Installation

```bash
omarchy theme install https://github.com/oguzaybilir/omarchy-oblr-theme
```
